Project Features & Capabilities

Key components built into this application
  • Gamified Habit Tracking & Daily Quests

    Organize habits across Coding, Fitness, Study, Mindset & Health with quest difficulty tiers (E-Rank to S-Rank) and instant XP rewards.

  • Sanctuary Mastery Rank Progression

    Level up from 1-Tomoe Initiate and Chūnin up to Mangekyō Sharingan and S-Rank Lunar Sovereign as you conquer daily targets.

  • Shinobi & Celestial Spirit Familiars

    Unlock companions like Kage Wolf, Homura Fire Fox, Karasu Crow, Ryuujin Dragon, and Susanoo providing passive XP multipliers.

  • Atomic Streak Flame & Calendar Heatmaps

    Mathematically accurate streak calculations, dynamic month traversal, daily reflection logs, and habit consistency analytics.

  • Analytics Dashboard & RPG Attribute Radar

    7-day completion rates, 30-day consistency metrics, category breakdowns, and dynamic RPG character stat radars.

  • Turso Distributed Cloud Database (LibSQL / SQLite on AWS Mumbai)

    Serverless edge database with automated relational schema migrations, sub-50ms query response, and seamless cloud synchronization across all devices.

  • Multi-Tenant Security & Razorpay Payments

    Encrypted authentication with JWT HTTP-only cookies, Bcrypt password hashing, and full Razorpay Payment Gateway integration for premium pass checkout.

How It Was Built (AI-Augmented Engineering & Vision)

System architecture, database schema, and human-directed AI workflow
AI-Augmented Development with 100% Human Vision & Architecture

This application was built utilizing modern AI-assisted engineering workflows. As an aspiring software engineer actively learning Java, Backend Development, and Databases, I directed every architectural, structural, and creative decision: conceptualizing the lunar aesthetic, mapping the UI/UX component hierarchy, designing the relational database schema for Turso Cloud DB, formulating streak algorithms, and integrating Razorpay payments. AI was leveraged as an intelligent multiplier for high-speed code generation, modular refactoring, and debugging.
